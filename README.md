# Neural Marionette V2 · 数字提线木偶

用摄像头捕捉手部动作，实时操控 Tripo 鹿角机甲。新版支持待机、疾跑、旋身跃起、负重、下蹲和跳跃，并保留原机器人切换、个人手势录制、背景音乐和舞台录像。

![V2 鹿角机甲，摄像头关闭，无真人影像](neural-marionette/docs/images/camera-off.png)

## 快速开始

安装 Node.js 22.12 或更高版本，在仓库根目录运行：

```sh
cd neural-marionette-v2
npm ci
npm run dev
```

打开 **http://127.0.0.1:5179/**。安装依赖需要联网；手部模型、WASM、角色和配乐均随项目提供，应用运行时在浏览器本地处理摄像头画面。不要直接双击 `index.html`。

macOS 安装依赖后也可双击 [启动数字提线木偶.command](neural-marionette-v2/启动数字提线木偶.command)。首次使用建议先关闭摄像头试播六种动作，再连接摄像头测试。

## 本次更新

- 默认加载鹿角机甲，可一键切回原机器人，也可导入兼容的已绑骨 GLB。
- 疾跑使用拇指、小指伸开，中间三指反复摆动的内置规则。两路运动检查减少手掌参考点抖动造成的误跑；停指后应停止。
- 手势录制先准备 3 秒，再等待完整手掌进入画面，默认采样 6 秒，可选 4 / 8 秒。
- 正常操控和手势录制互斥；录制或管理样本后，点击「返回正常操控」恢复控制。
- 保留个人样本导入导出、混合识别、电子氛围配乐和最长 25 秒舞台录像。

## 手势与动作

| 动作 | 内置手势 | 试播键 |
| --- | --- | --- |
| 待机 | 张开手，放松停留 | 1 |
| 疾跑 | 拇指、小指伸开，中间三指反复摆动 | 2 |
| 旋身跃起 | 只伸食指，像转钥匙一样转腕 | 3 |
| 负重 | 拇指与食指捏合并保持 | 4 |
| 下蹲 | 握拳向下压，保持拳头 | 5 |
| 跳跃 | 下蹲后快速上提并张手 | 6 |

疾跑示范姿势为手掌朝下、手背朝前或朝上；当前没有严格判定手掌相对地面的方向。规则还要求独立手指运动，静止手型不会持续驱动内置疾跑。个人录制的疾跑可使用不同控制方式，测试内置规则时请选择「原有手势规则」。

摄像头推理与录像合成都在本机完成。样本仅存关键点，保存在当前浏览器与站点地址的 localStorage；5173 与 5179 是不同存储空间，旧版样本需导出 JSON 后再导入新版。舞台录像可能包含摄像头画面，请自行决定是否分享。

## 版本与实现

| 目录 | 内容 | 开发端口 |
| --- | --- | --- |
| [neural-marionette-v2](neural-marionette-v2/README.md) | 当前推荐版本：鹿角机甲及改进的运动判断 | 5179 |
| [neural-marionette](neural-marionette/README.md) | 原机器人版本，保留供比较 | 5173 |

技术栈为 JavaScript、MediaPipe Hand Landmarker、Web Worker / WASM、Three.js、Canvas 2D 和 Vite。手部模型输出 21 个关键点，内置规则和个人样本匹配选择动作，程序化动画驱动角色骨架；不需要 TouchDesigner、API Key 或大语言模型。

鹿角机甲包含 100,754 个三角面、15 根骨骼，没有内置动作片段。运行 GLB、原始静态 GLB 和 Blender 源文件均已提供。手指未逐指绑骨，大幅动作可能出现装甲穿插或关节拉伸。

## 开发与验证

在 `neural-marionette-v2` 中执行：

```sh
npm test
npm run build
```

V2 有 65 项 Node 单元测试；浏览器脚本验证模型加载、动作切换及合成手势流程，需另外安装 Python Playwright。部分历史脚本包含本机路径，需要按自己的环境调整。合成测试不能代替真人手势准确率或端到端延迟验收。
