# Neural Marionette · 数字提线木偶

用摄像头手势操控 3D 机器人。项目介绍、默认手势表与完整安装说明见 [仓库首页 README](../README.md)。本目录是应用源码与运行目录。

## 安装与启动

需要 Node.js 22.12 或更高版本、npm，以及支持 WebGL2 的桌面浏览器。当前主要在 macOS + Chrome 下验证。

在本目录执行：

```sh
npm ci
npm run assets
npm run dev -- --port 5173 --strictPort
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。完成首次安装后也可双击 [启动数字提线木偶.command](启动数字提线木偶.command)。依赖与模型资源准备完成后可本地运行，无需 Python 服务、TouchDesigner 或大模型 API。

## 当前功能

- MediaPipe Hand Landmarker 在 Web Worker 中提取单手 21 个关键点。
- 六种动作：待机、疾跑、旋身跃起、负重、下蹲、跳跃，配合协调的全身动画与落地过渡。
- 个人手势录制、骨架回放、绑定、样本导入导出与混合识别；只录想自定义的动作即可。
- Three.js 机器人与 Canvas 2D 摄像头、骨架、提线合成，支持镜像、画质调节与诊断导出。
- 原创背景配乐《霓光轨道》，随操控播放，可暂停、调音量并记住偏好。
- 最长 25 秒舞台录像，以及供系统区域录屏使用的手动优化开关。

## 录制并绑定手势

1. 连接摄像头，等待追踪准备完成，选择机器人动作。
2. 点击「录制我的手势」，在 2 秒倒计时内把手放入画面，再用约 1.6 秒做一次完整动作。点击按钮时不要求手在镜头内。
3. 录制成功后查看骨架回放，点击「保存并绑定」。空白或不完整样本会提示重录。
4. 保存后默认进入混合模式：已绑定动作使用个人样本，其余动作继续用原规则。

「录制我的手势」在摄像头未就绪或正在录制时变灰；「保存并绑定」在录制成功前变灰。预览下方显示当前连接与检测状态。切换到后台会关闭摄像头，返回后需要重新连接。

样本仅存在当前浏览器、当前完整站点地址的 localStorage 中，不随 Git 提交保存。更换浏览器或地址前，请先导出样本备份。详见 [手势录制说明](docs/GESTURE_STUDIO.md)。

## 录制舞台视频

「录制 25 秒」与个人手势录制是两个独立功能。舞台录像自动使用 **720p / 30 帧、4 Mbps 目标码率**，减少滤镜与辉光负担，停止保存后恢复原画质；若原本手动开启了录屏优化，则继续保留。

使用 macOS 区域录屏时，先勾选「录屏优化」，录完取消。优先导出 H.264 MP4，失败时尝试 VP8 WebM 等可用格式；实际帧率和码率取决于浏览器与设备负载。当前内置录像不包含配乐和麦克风。详见 [录屏性能与排查](docs/RECORDING.md)。

## 开发验证

```sh
npm test
npm run build
```

当前 37 项单元测试覆盖手势规则、动画、轨迹匹配、混合路由与录制控件状态。浏览器流程测试位于 `tests/`；其中的模拟摄像头与合成手势用于流程验证，不能替代真人识别准确率和端到端延迟验收。构建输出位于 `dist/`。
