# 手势录制入口修复与文档更新 · 2026-09-15

摄像头与模型就绪后即可开始手势录制，不再要求点击瞬间检测到手。利用原有 2 秒倒计时让操作鼠标的手返回画面；保留空样本与不完整样本拒绝。增加连接和检测状态说明，防止重复连接重启摄像头。补充控件回归测试，当前共 37 项单元测试。同步更新仓库首页与应用 README、源码目录及最新操作说明。

# 录屏性能优化 · 2026-09-15

新增自动／手动录屏优化：720p、30 帧、4 Mbps 目标码率，优先 H.264，回退 VP8。缓存静态背景，按已完成的画面请求捕获，移除 WebGL 持久绘图缓冲；录屏时减少光效与滤镜。推理派发独立于渲染限帧，保留手势样本与动作节奏。录像结束或失败后清理视频轨道并恢复设置。详见 [录屏说明](docs/RECORDING.md)。

# 背景配乐 · 2026-09-15

新增原创电子配乐 Neon Orbit：本地循环播放、淡入淡出、音量与开关记忆，摄像头和动作试播联动，退出操控或后台时暂停。手势样本与识别逻辑不变。

# 混合识别 · 2026-09-14

已绑定动作使用个人样本，其他动作沿用原有规则。保留纯规则与纯个人模式；切换不会修改样本，有样本时刷新默认混合模式。

# 手势录制与绑定 · 2026-09-13

新增倒计时录制、骨架回放、六状态样本绑定、本地存储与导入导出。用个人样本匹配轨迹，支持补录、静止/动态区分和相似样本拒绝。原规则可随时切回。修改前已创建快照 `65a4f16`。

# 手势分离 · 2026-09-13

根据真人反馈：疾跑改为双指朝下、其余收起并前后摆动；旋身改为单独伸食指并转腕。换手型清空运动缓存；加入双指方向、拇指收回及靠近/远离镜头的摆动判定。23 项单元测试覆盖手型互斥、方向、静止、镜像、深度摆动及动作切换。

# 动作表现强化 · 2026-09-13

疾跑步频提高约 2.1 倍，加入蹲压前冲与腾空步态；转身改为 1.06 秒蓄势、跃起转一圈、落地收势。重新编排负重、下蹲、跳跃与待机，加入短暂轨迹和冲击光环。详见 docs/MOTION_V3.md。

# 第二版动作控制 · 2026-09-13

新增六种全身动作、手势规则、动作过渡、脚踝 IK、全幅摄像头合成与动作试播。降低位置跟随平滑，修复手掌旋转串扰。详见 docs/MOTION_V2.md；新版验证证据位于 docs/evidence/v2。
