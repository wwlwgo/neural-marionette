当前支持 [录制自己的手势](GESTURE_STUDIO.md)：选择动作、示范、回放、绑定。下文为原有规则和基础控件，可选择混合模式、原有规则或仅个人录制。混合模式下，已绑定动作使用你的样本，其他动作沿用下文规则；无需录全六种动作。

# 操作与参数

| 控件 | 用途 |
| --- | --- |
| 开启/连接摄像头 | 获取本机视频并启动 MediaPipe |
| 关闭摄像头 | 终止 Worker、停止视频轨道 |
| 模拟操控 | 明确标注的合成骨架输入；鼠标/触摸控制；不满足真人验收 |
| 重新校准 | 手掌稳定保持，建立新的中立姿态 |
| 位置跟随强度 | 0.3–2.0 倍的小幅位置修饰增益，不改变主动作幅度 |
| 镜像 | 同时镜像视频、点与控制空间；切换后重新校准 |
| 高/均衡/轻量 | 高与均衡 1080p，不同辉光与粒子数；轻量 720p |
| 调试 | 展开五个关节测试滑块与 raw/filtered 腕点和食指尖 |
| 重置 | 恢复增益、清空滑块覆盖、重新校准 |
| 录制 25 秒 | 自动开启 720p / 30 帧录屏优化，提前停止也能保存，结束恢复原画质 |
| 录屏优化 | 系统区域录屏前手动开启；结束后取消勾选恢复原画质 |
| 导出诊断 | 下载当前会话性能与配置 JSON |
| 播放／暂停配乐 | 开始操控时默认播放；可单独试听或关闭 |
| 配乐音量 | 0–100%，记住音量与开关；0% 静音 |
| 全屏 | 把互动舞台放大，保留控制按钮 |

## 动作控制

手势规则见 [第二版动作说明](MOTION_V2.md)，最新动作表现见 [动作强化说明](MOTION_V3.md)。先放入张开的手掌，稳定片刻。食指与中指朝下伸出、其余手指收起并前后摆动来疾跑；只伸出食指、其余收起并转动手腕来旋身跃起、拇指食指捏合负重；握拳下压下蹲，再快速上提并张手跳跃。手掌大致朝向摄像头，保持所有手指可见。

点击动作库或按 1–6 进入模拟试播；试播会关闭摄像头。返回真人控制请点击「返回摄像头手势控制」。跳跃和旋身跃起都会先完整落地，再切换动作。重置可回正机器人。

## 默认值

- 摄像头目标 1280×720 / 30 FPS；浏览器可协商成设备实际支持的值，导出的 camera settings 为实际值。
- 追踪：检测 0.65、存在 0.65、IoU 追踪 0.60，单手。
- 丢手容忍 250 ms；数据停滞 800 ms；无更新 5 秒报错。
- 点滤波 22 ms；位置修饰滤波 45 ms；中立恢复 650 ms。
- 位置修饰死区 0.018；修饰角度上限 35°；主动作使用独立的轨迹和过渡。
- 默认均衡 1920×1080，目标 60 FPS；低档 1280×720。
- 录像 25 秒 / 1280×720 / 30 FPS / 4 Mbps 目标码率，实际帧率与码率取决于浏览器负载和编码器。优先 H.264 MP4，失败回退 VP8 WebM 等可用格式。
- 录屏优化将渲染限制为 30 FPS，减少粒子、停用重滤镜和辉光；手势规则、个人样本和动作时长不变。详见 [录屏性能说明](RECORDING.md)。

UI 调节保留到本次页面会话结束。修改持久默认值应编辑 config/app_config.json，然后重新加载。不存在隐式永久修改或远程配置。


## 疾跑与旋身的手型分离

疾跑要求食指和中指都伸直且大致指向画面下方，拇指、无名指、小指收回。前后摆动可表现为手腕移动、双指摆动或靠近/远离镜头；静止保持手型不会启动，停止摆动后收势。

旋身跃起只接受食指伸直，中指、无名指、小指与拇指收回，再像转钥匙一样转腕。双指转腕不再触发旋身，单指平移不再触发疾跑。换手型会清空上一手型的运动缓存，需要在新手型下产生运动才能触发。

空中旋身仍会完成落地后切换；短暂的识别保持和完整动作收尾，不表示新手型误触发了旧动作。真人遮挡或侧对镜头仍可能影响指节识别。
