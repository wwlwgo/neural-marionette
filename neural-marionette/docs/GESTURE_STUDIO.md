# 手势录制与绑定

修改前基线已保存为本地 Git 提交 `65a4f16`。该提交不包含手势录制模块；此前强化动作、分离手型规则、测试和预览均已保存。

## 使用

1. 在 Chrome 打开本地页面，找到舞台下方的「录制并绑定我的手势」，连接摄像头。
2. 选择要触发的动作，例如疾跑。让整只手出现在小取景窗，确认骨架能跟上手部。
3. 点击「录制我的手势」。倒计时两秒后，约 1.6 秒内自然做一次完整动作。无需符合原有文字规则。
4. 观察骨架回放。确认录到了想要的动作后，点击「保存并绑定」；录得不好可重录或取消。
5. 保存后自动切到「混合模式」。再做一次相同动作，查看“最接近”和当前状态。每个动作最多补录至三段，建议包含略有不同的速度和位置。
6. 只需录你想自定义的动作。例如仅录疾跑时，疾跑使用样本，旋身跃起、负重、下蹲、跳跃和待机仍用原有规则，无需补录。混合模式下样本匹配成功优先触发，已绑定动作的旧规则停用；待机样本不会阻止其他动作的原规则。

识别方式还保留「原有手势规则」和「仅我的录制手势」；后者只触发已绑定动作。切换模式不会修改样本。

宽松度默认 0.28。提高更容易匹配，也更容易误触发；优先补录有代表性的样本，不要一开始就把宽松度拉满。

## 保存与分析

只保存 21 个手部关键点、采样时间、画面宽高比、动作标签和样本时间，不保存摄像头视频、不调用外部接口。数据写入当前浏览器、当前本机地址的 localStorage；另一个浏览器或端口不会自动共享。

「导出样本给我分析」下载 JSON 文件，之后可把文件提供给 Codex，直接分析实际轨迹，不必只用语言描述。「导入并替换样本」会替换当前浏览器内的样本集合。浏览器清理数据也会影响保存，因此建议导出备份。

移除按钮只在你主动点击时移除对应样本。录制取消不会影响已保存样本。刷新后保留样本：有样本时默认混合模式，无样本时默认原有规则。已有疾跑样本可直接继续使用，不需要重新录制。

## 实现与边界

此版本是本地示例轨迹匹配，不是训练新的神经网络。MediaPipe 继续负责提取手部关键点。录制轨迹经过手掌尺度和位置归一化，保留朝向、手指相对位置、腕部平移与距离变化；短时间窗口通过动态时间规整比较，结合运动幅度判断。不同状态过于接近时拒绝触发；录制质量不足或间断超过 250 ms 时拒绝保存。

识别需要观察一小段轨迹，不能承诺零延迟。速度、遮挡、掌心侧向、左右手或手离镜头距离变化很大时，可能需要补录样本。若小取景窗中的骨架本身识别错了，应先调整拍摄角度或光线，录制绑定无法弥补错误的关键点输入。

录制/回放期间动作控制暂停；已经在空中的机器人仍先完成落地。关闭摄像头或切换输入会取消未完成的录制。模拟操控模式不能作为录制输入。

## 验证

- 36 项单元测试：保留既有动作与手势测试，新增录制完整性、丢手拒绝、导入校验、不同于原规则的动作绑定、动态与静态区分、相似样本拒绝、样本序列化恢复及混合模式路由。
- `tests/studio_browser_test.py`：录制、骨架回放、保存绑定、个人样本实际驱动机器人、导出导入、刷新恢复、混合模式下未绑定动作沿用原规则、切换模式保留样本、无手拒绝、取消录制及手机布局。
- 证据位于 `docs/evidence/gesture-studio/`；测试用合成手势和模拟摄像头，不能替代真人准确率验收。


## 录制按钮变灰时（2026-09-15 更新）

摄像头与追踪模型就绪后，「录制我的手势」即可点击，不再要求点击瞬间手必须在镜头里。选择动作、点击录制后，有 2 秒时间把操作鼠标的手放回画面，再用约 1.6 秒示范动作。没有捕捉到完整序列时会提示重录，不能保存空样本。

摄像头未连接、正在加载或已在倒计时／录制时，录制按钮仍会禁用。预览下方会显示连接与手部检测状态。「保存并绑定」只在录制成功、出现骨架回放后启用。切换到后台会关闭摄像头，返回后需重新连接。
