# 背景配乐：Neon Orbit · 霓光轨道

为数字提线木偶编排的原创程序化电子配乐：100 BPM、32 小节、76.8 秒，立体声。温和的合成器和弦、低频脉冲、轻鼓点与分散琶音配合紫色机械外壳和金色提线；无人声，没有使用第三方歌曲或采样。

## 使用

- 点击连接摄像头或开始动作试播时，默认以 25% 音量播放。
- 舞台工具栏下方提供播放／暂停与音量控制，也可单独点击「播放配乐」试听。
- 关闭摄像头、退出模拟操控时淡出并暂停；后台暂停，返回页面时，仅在仍处于操控／试听状态且配乐开启时恢复。真人模式原本会在进入后台时断开摄像头，回来后需重新连接。
- 音量和开关状态保存在当前浏览器；如果上次关闭了配乐，下次开始操控不会强行打开。设为 0% 时静音。
- 首次打开页面不会直接出声，播放通过用户点击启动。资源加载失败会显示重试入口，不阻塞手势操控。
- 音乐在浏览器音频通路中播放。现有「录制 25 秒」仍只录制舞台画布，没有混入配乐，也不录麦克风。

## 文件与实现

- [配乐 MP3](../public/music/neon-orbit.mp3)：约 1.54 MB，随项目本地加载。
- [播放控制器](../src/music.js)：Web Audio API 加载、解码、循环、淡入淡出、暂停续播和偏好保存。
- [编曲与合成脚本](../scripts/compose-music.mjs)：固定种子的噪声打击乐、正弦合成器、和弦编排与循环延迟尾音；不在实时交互时执行。
- [浏览器验证](../tests/music_browser_test.py)：使用真正 AudioContext 解码及分析输出信号，摄像头为模拟输入。结果位于 测试记录（本地记录，未随公开版本提供）。这不代表真人主观听感测试。

音频只加载、解码一次；开始播放时淡入 0.65 秒，暂停时淡出 0.2 秒；AudioBufferSourceNode 循环播放，停止后保存播放位置，音频上下文暂停以减少空闲处理。切换动作不重新开始歌曲。

如需重新生成配乐，在项目子目录执行（开发者操作，需要 FFmpeg）：

```sh
node scripts/compose-music.mjs
```

脚本生成临时 WAV 母带并编码成本地 MP3，输出母带路径；普通安装与运行使用已生成 MP3，不需要 FFmpeg，也没有新增 npm 依赖。

浏览器音频启动与音量管理依据 [Web Audio 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)；循环接口见 [AudioBufferSourceNode.loop](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loop)。
