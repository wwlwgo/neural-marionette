# 动作表现强化：疾跑与旋身跃起

2026-09-13。依据用户对第二版“像走路、转身太慢、动作呆板”的反馈重新编排，手势规则和 Web 架构保持不变。

## 新的运动节奏

- **疾跑**：约 120 ms 蹲压，随后蹬地前冲；步态角频率由 8 提高到 17 rad/s（默认约 2.7 个完整左右步循环/秒）。短支撑、长回收，存在双脚同时离地的阶段。身体前倾、肩胸反扭、头部反向稳定、双臂大幅交替。角色斜向前方冲出约 0.72 个场景单位后，在舞台范围内持续疾跑，不无限跑出画面。
- **旋身跃起**：每轮约 1.06 秒；蹲压反向蓄势，腾空收腿并旋转 360°，屈膝落地再收势。持续转动手势时可以接续下一轮；方向在起跳时确定，空中不会突然反转。松开或切换手势时先完成本轮落地。
- **负重**：改为约 1.8 秒的蓄力、快速推举、头顶停留、慢速卸力，不再全程匀速正弦起伏。
- **下蹲**：快速下沉、轻微衰减回弹，左右手与脚位不完全对称，头部保持观察方向。
- **跳跃**：约 1.18 秒，向后摆臂蓄势、快速起跳、空中收腿和不对称抬臂、落地吸收冲击。
- **待机**：轻微重心变化、呼吸、肩臂和视线的错峰运动。

为快速动作增加短暂的手部金色轨迹和落地光环。系统“减少动态效果”偏好会关闭这两项附加效果。主要动作仍由用户主动触发。

## 验证与边界

19 项单元测试覆盖既有识别规则及新动作：起跑先压低再前冲、疾跑步频和腾空区间、旋身完整一圈并落地、连续旋转无角度跳变、全动作脚部 IK 可达和脚底水平。

浏览器验证包含六动作、旋身离地、跳跃落地、键盘、录制、模拟摄像头运行真实 MediaPipe、移动布局，以及合成关键点通过页面接口驱动动作的完整回放。证据在 `docs/evidence/v3/`。这些测试不代表真人手势准确率或端到端延迟实测。

预览 `recordings/actions-v3-SIMULATION.mp4` 为按钮驱动的模拟动作录制，保留第二版预览以便比较。此版是对用户描述的节奏与表现进行重新设计，未取得原项目动作资产，不声称逐帧复刻。

角色仍使用自制机械骨骼。脚部约束作用于虚拟舞台；摄像头场景没有真实地面识别。跃起旋转中途的手势切换会延后到落地执行，这是完整动作保护，不是识别耗时变长。
